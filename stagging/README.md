# データクレンジングと統合の習作

## 概要
データ整形・加工・統合を行う練習

## 作業意図・目的
加工を要する不備や欠損のあるデータ整形と統合。
AccessクエリとVBAで行っていた実務作業に近しい工程を
SQL・Pythonで再構築することで、データ構造やコード記述方法を学ぶ

### SQLite
- VIEWを使用したマスタ生成
- window関数による最新レコード取得
- SQLのみで集計・整形処理を実装
- Pythonでのコード記述を理解しやすくするための基礎構成

### Python
- pandasによるデータ加工
- 受注データ・商品マスタ・得意先マスタを個別モジュール化
- mergeによる結合処理
- CSVベースのETL処理


## folders

### PY
- Python（主にpandas）による集計処理ファイル一式

### SQL
- SQLite用のDBと集計処理ファイル一式

### CSV
- 元データCSV一式。スプレッドシートで作成し書き出したもの
- SQLite DBへの取込に使用
- Python集計の参照元
